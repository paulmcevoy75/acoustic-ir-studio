# Third-party components

Acoustic IR Studio is licensed under the GNU GPL v3.0 (see `LICENSE`). The Windows download also bundles the components below, each under its own licence.

| Component | Used for | Licence |
|---|---|---|
| Python | runs the app | PSF License |
| NumPy, SciPy | signal processing | BSD-3-Clause |
| Matplotlib | graphs | Matplotlib License (BSD-style) |
| sounddevice, PortAudio | audio input/output | MIT |
| soundfile, libsndfile | reading/writing audio files | BSD-3-Clause / LGPL-2.1 |
| pycaw, comtypes | Windows input levels | MIT |
| imageio-ffmpeg | finding/running FFmpeg | BSD-2-Clause |
| FFmpeg | reading MP3 / video files in Tone Match | GPL v3 build. Source code: https://ffmpeg.org/download.html |
| PyInstaller bootloader | packaging the .exe | GPL v2 with a bootloader exception |
| Tcl/Tk | the window toolkit | Tcl/Tk License (BSD-style) |

Each component's own licence text is included in the download where its package provides one.
